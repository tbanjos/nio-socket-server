There are several ways to check the performance of a Java TCP server:

Use a tool like Apache JMeter to simulate multiple clients and measure the server's response time and throughput.

Monitor the server's CPU and memory usage using a tool like JConsole or VisualVM to see how it handles different workloads.

Use a profiler like JProfiler or YourKit to identify bottlenecks and optimize the server's performance.

Test the server's scalability by increasing the number of concurrent clients and measuring the server's response time and throughput.

Monitor the server's network traffic using a tool like Wireshark or tcpdump to see how it handles different types of requests.
